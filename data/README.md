# Data attribution

Source: Cortez, P. (2008). Student Performance [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T

Dataset page: https://archive.ics.uci.edu/dataset/320/student+performance

License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

`student-mat.csv` and `student-por.csv` are the original semicolon-separated files, with 395 and 649 records respectively. Grade Lab analyzes the subjects separately. Reports and plots are derived works. The source URL and mathematics checksum are recorded in `reports/metadata.json`.

G1 = first-period grade, G2 = second-period grade, G3 = final grade, all on a 0–20 scale. Study time is ordinal: 1 (<2 hours/week), 2 (2–5), 3 (5–10), 4 (>10). Travel time is also ordinal. Refer to UCI for the complete dictionary; do not interpret category numbers as literal hours.
